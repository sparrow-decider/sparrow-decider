Methodology

  • RobotBench v0: 55 robot decisions written by hand, separately from the robot training generator.
  • MASSIVE: Amazon MASSIVE 1.1 en-US test, 600 utterances, never trained on. Evaluation only (CC BY 4.0).
  • JevBench: public tasks, local v1.5 proxy, not leaderboard scores. Evaluation only (MIT).
  • Laptop timings: local runs, one CPU core, per question; the runtime (C or numpy) is named next to each value.
  • ESP32-S3 timings: measured on the board: ESP32-S3 (QFN56 rev0.2), 240 MHz, 16 MB flash, 8 MB PSRAM.
  • Tables are generated by bench/aggregate.py from bench/results/. Model IDs are shown exactly as run.

Where it falls short

Open-ended language it never trained on: well behind the 2B (MASSIVE domain routing 0.37-0.67 across released Sparrow models vs 0.86).

Yes/no judgement on JevBench is near chance at every tier.

pico answers only the questions it was compiled for.

RobotBench was written by hand, separately from the robot training generator. MASSIVE was never trained on, and it is where the gap to the 2B shows.
